🎯 Problema

Como o desempenho comercial varia no tempo e entre regiões, canais, categorias e produtos? Quais indicadores ajudam a avaliar a experiência do cliente?

🧹 Tratamento

  • Conversão de datas
  • Verificação de ausentes e duplicidades
  • Padronização textual
  • Engenharia de atributos

📌 KPIs

  • Faturamento
  • Lucro e margem
  • Unidades vendidas
  • Avaliação
  • Prazo de entrega

🔎 Principais descobertas

  • Região líder: Sudeste
  • Categoria líder: Beleza
  • Canal líder: Marketplace
  • UF líder: RJ
  • Avaliação média: 3.77/5
  • Prazo médio: 8.5 dias

🧰 Tecnologias

Python • Pandas • NumPy • Matplotlib • Seaborn • Streamlit • SQLAlchemy • SQLite • Jupyter • GitHub • GitHub Pages

🚀 Funcionalidades

  • Filtros múltiplos e KPIs dinâmicos
  • Análise temporal
  • Comparações por região, UF, canal, categoria e produto
  • Correlação estatística
  • Persistência e modelagem relacional com SQLite/SQLAlchemy
  • Download dos dados filtrados
  • Dashboard organizado em seções

📚 Metodologia

O projeto segue o fluxo de leitura → limpeza → preparação → engenharia de atributos → análise exploratória → KPIs → visualização → interpretação → conclusão. O notebook documenta o processo e o Streamlit disponibiliza a análise de forma interativa.
